# DistribuPro — Distribution Management System

A mobile-friendly browser demo for managing a small distribution operation.

## Included
- Dashboard: sales value, order count, stock units and outstanding balances
- Product catalogue and stock adjustments with low-stock alerts
- Retailer/customer directory
- Sales order creation with stock deduction and basic outstanding tracking
- Printable invoice view
- CSV export for sales orders
- Browser localStorage persistence

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then Save.
4. Wait for the deployment. The site should be available at:
   https://hareeshlal.github.io/Distribution/

## Important demo limitations
This is a frontend prototype. Data stays in the browser/device where it is entered. It does not yet provide cloud sync, multi-user login, role permissions, GST-compliant invoicing/e-invoicing, purchase orders, delivery management, payment gateway integration, backups, or audit logs. Do not enter real customer or financial information until a secure backend and access controls are added.
